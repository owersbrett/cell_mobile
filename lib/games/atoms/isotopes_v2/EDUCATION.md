# Isotopes v2 — Education (E)

## The lesson, in the mechanic
An **isotope** is one of several forms of the same element that differ only in
neutron count. The game makes you *feel* the two independent axes:

- Dial **PROTONS** and the **element changes** — the readout's name, symbol and
  electron-shell count all update live. Protons (the atomic number Z) ARE the
  element's identity.
- Dial **NEUTRONS** and the element **stays put** while the **mass number A
  changes** — you are sweeping through that element's isotopes. `A = Z + N`.

Building a nuclide IS stating its proton and neutron count, so the move is the
chemistry — there is no busywork wrapped around a fact.

## Concepts taught
- **Atomic number (Z) = protons = the element.** Change Z and you change which
  element you have; the periodic identity is set by protons alone.
- **Mass number (A) = protons + neutrons.** Shown live as the `A` chip and as the
  superscript in `¹⁴C`-style notation.
- **Isotopes = same Z, different N.** The pool serves real isotopes (protium /
  deuterium / tritium; C-12 / C-13 / C-14; O-16 / O-17 / O-18; the chlorine and
  argon pairs; Fe-54 / Fe-56 / Fe-58), so the player meets recognizable nuclides.
- **Isotope notation.** The prompt ladder ends at raw `¹⁴C` notation, so the
  player learns to read "superscript A + element symbol".
- **Electron count of a neutral atom = Z.** The faint electron shells around the
  nucleus track the proton count, reinforcing that Z is the element's identity.

## The difficulty ladder (preserved from v1)
Prompts get terser as you solve more — the same nuclide is asked in harder forms:
1. **Counts** — `6 PROTONS · 8 NEUTRONS` (handed to you).
2. **Mass name** — `CARBON-14` (recall Z, derive N from A).
3. **Neutron count** — `OXYGEN · 10 neutrons` (recall Z, add N).
4. **Notation** — `¹⁴C` (read the symbol → Z, read A → N).
The element pool also widens (Z≤8 → 14 → 20 → 26) as you progress.

## Accuracy notes
- The element table (Z = 1–26, H→Fe) and every isotope in the pool are real.
- Electron shells use the introductory 2-8-18 period model for the visual only;
  they reinforce "electrons = Z" and are not the graded mechanic.

## Why this is fun *and* educational
v1 taught the lesson but buried it under a ±1 tap-grind, so "harder" meant
"slower". v2 keeps the exact same teaching and makes reaching a value fast, so
the challenge is the *chemistry under time pressure* — read the notation, find
the element, set the mass — accelerating to a shared ×2 surge. The skill is
recall + the fastest path from your current nuclide to the next, which is exactly
the proton/neutron reasoning the lesson is about.

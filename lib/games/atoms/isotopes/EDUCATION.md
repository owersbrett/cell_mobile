# EDUCATION.md — Isotopes

> The E in GAMES. What the player actually learns, and how the mechanic teaches
> it rather than telling it.

## Learning objective

Understand the two numbers that define an atom, and what an isotope is:

1. **Atomic number (Z) = number of protons = the element's identity.** Change
   the proton count and you change the element, full stop. Z=6 is carbon; you
   cannot have carbon with 5 protons.
2. **Mass number (A) = protons + neutrons.** It counts the nucleons (the heavy
   particles), so it tracks how heavy a specific atom is.
3. **Isotopes** are atoms of the *same element* (same Z) with *different neutron
   counts* (different N, therefore different A). Carbon-12, carbon-13, and
   carbon-14 are all carbon — only the neutrons differ.
4. **Isotope notation** ᴬX: the superscript before the symbol is the mass number
   (e.g. ¹⁴C = carbon with mass number 14, i.e. 6 protons + 8 neutrons).

## How the mechanic teaches it (not tells it)

- **Protons define the element — felt live.** The instant you turn the proton
  dial, the big readout's name and symbol change (5 → BORON, 6 → CARBON). You
  *discover* that Z is the identity instead of being told; the only way to make
  the named element is to find its proton count.
- **Neutrons make isotopes — felt live.** Turning the neutron dial leaves the
  element name untouched while the mass number A ticks up. You see, directly,
  that adding neutrons gives a heavier version of the *same* element — that's an
  isotope, not a new element.
- **Two independent axes.** The prompt card carries two separate confirm pills —
  ELEMENT (Z) and ISOTOPE (N) — so you learn that "right element" and "right
  isotope" are different conditions you satisfy independently.
- **A = Z + N is unavoidable.** The readout shows Z, N, and A side by side and A
  always equals Z + N, so the relationship is reinforced every single tap rather
  than stated once.
- **The notation is taught by use.** As prompts accelerate they switch to raw
  ᴬX notation (¹⁴C); by then the player has built enough nuclides that reading
  "mass 14, symbol C → 6 protons, 8 neutrons" is fluent, not cryptic.

## Misconceptions corrected

- *"Isotopes are different elements."* → No: same element (same Z), different
  neutron count. The element name never changes when you move neutrons.
- *"The mass number is the number of protons."* → No: A counts protons **and**
  neutrons; Z alone is the protons.
- *"Adding a neutron changes what element it is."* → No — only protons do that.
- *"Carbon-14 means 14 protons."* → No: it means mass number 14; carbon is
  always 6 protons, so carbon-14 has 8 neutrons.

## Curriculum hooks

- Maps to middle/high-school chemistry: atomic structure, atomic number vs. mass
  number, isotopes, and isotope notation. A natural lead-in to average atomic
  mass and radioactive dating.
- Cross-scale: builds on Atom Builder (assembling atoms up the noble ladder) and
  feeds forward to bonding/molecular-scale games where element identity (Z)
  determines chemistry.

## One-sentence takeaway

> Protons (Z) decide *which element* an atom is; neutrons decide *which isotope*
> — and the mass number A is just protons plus neutrons.

# EDUCATION.md — Transcribe

> What the player actually learns, and exactly where the mechanic teaches it.
> The lesson must be IN the loop, not in a wall of text.

## Learning objective

By playing, a learner internalizes the first two steps of the **central dogma**:

1. **Transcription** — DNA is copied into mRNA by complementary base pairing.
2. **Translation** — mRNA is read in three-letter **codons**, each coding one
   amino acid; a chain of amino acids is a protein.

`DNA → mRNA → protein.`

## The rules, taught by doing

### Base pairing (the core loop)
- DNA **A → mRNA U**, **T → A**, **C → G**, **G → C**.
- The single most important takeaway is reinforced every single tap: **mRNA has no
  thymine** — DNA's T pairs to A, and DNA's A pairs to **uracil (U)**. There is no
  "T" button on purpose; the player physically cannot mis-key thymine into RNA.
- The pairing legend (`A→U  T→A  C→G  G→C`) sits on screen the whole round, so the
  rule is always one glance away — recall, then recognition, then reflex.

### Codons and translation (the codon stage)
- Every three transcribed bases close one codon; the game groups them visually
  (three progress dots) and pops the amino acid it codes (e.g. `AUG → Met`, the
  start codon).
- In the codon stage the player actively **matches the amino acid** to the codon,
  so the abstract codon table becomes a thing you do, not memorize. Wrong guesses
  reveal the answer with no penalty — the loop teaches rather than punishes.
- Stop codons (`UAA`, `UAG`, `UGA`) surface as the no-amino case, hinting at how
  translation terminates.

## Misconceptions actively corrected
- "RNA is just like DNA" → no: **U replaces T**, enforced by the button set.
- "One base = one amino acid" → no: it takes a **codon of three**.
- "The complement is the same base" → no: pairing is A↔U/T, C↔G, never like-to-like.

## Potato thread
A potato's starch-building enzymes, its disease-resistance proteins, its very
shape — all are proteins, and every one was transcribed from potato DNA exactly
this way. Build the strand, and you're running the same machinery that builds a
spud.

## Accuracy notes
- The codon table used is the **standard genetic code** (64 codons), read 5'→3'.
- Real RNA polymerase reads the template strand 3'→5' and synthesizes mRNA 5'→3';
  the game abstracts directionality to keep the loop one-tap simple, but the
  *pairing* and *codon → amino acid* mappings are biologically correct.

# POTATUHS.md — Circulate v2

How `circulate_v2` carries the brand.

## Voice & framing
Circulate v2 hands you the body's dispatch desk while the heart is already
pumping. On-brand earnestness about an absurd premise: you are, sincerely, a
potato's oxygen-logistics operator. Butter would pitch it straight — *"The blood
goes out, the blood comes back. You just make sure the oxygen reaches the parts
that need it, and you reload at the lungs. Don't worry about it."* Russ would eye
the draining charge magazine — *"uhhh... so if I run out I just... can't?"*
Correct. That's the whole lesson.

## Look
- Dark-mode Potatuhs system (`theme/potatuhs.dart`): `inkDeep` field, an
  `inkPanel` fact strip, on-brand arterial **crimson** as the accent. The CODE
  RED climax shifts the atmosphere and glow toward **Fiery Orange** — the
  brand's energy colour turned up for the crescendo.
- Canvas-drawn anatomy: a pumping heart whose blood lerps red↔blue with the
  reserve, a refuel-lit lungs node, arteries to each organ, organ O₂ ring
  gauges, travelling red/blue blood. No raster assets — consistent with the
  cell_mobile look.
- Type: Outfit for all UI; Bowlby One SC (display) only for the CODE RED
  callout — fixed marquee text, per the design rule.

## Fit in the catalog
- **Scale:** organSystem (the body-wide tier of Explore The Cell).
- The UX-pass **alternative** to `circulate`: ships alongside the original so
  both are A/B-comparable in-app; a later judge picks the keeper (loser kept,
  `enabled: false`). This is the GAMES rubric's second pass — same lesson,
  sharpened fun.
- Reinforces the cell_mobile through-line: zoom out from organelles to the whole
  body and it's the same idea — a system of coupled loops you can actually
  operate, and a potato runs its own transport loops too.

## Brand-safe guardrails
- Education never bends to fun: the systemic/pulmonary coupling IS the lesson,
  so the brand's "earnest about the premise" promise holds — the absurd framing
  sits on top of correct physiology.
- Perf discipline (one Ticker → one Painter, capped FX) keeps it deploy-clean on
  `explore-the-cell.web.app` — the launch artifact stays smooth.

# Pattern Lock v2 — EDUCATION.md (the E in GAMES)

## What it teaches
**Sequences and the rules that generate them** — the idea that a few simple
rules produce rich structure. This is the "somethings" thesis in miniature:
order falling out of almost nothing. The lesson is **unchanged from v1**; only
the delivery was sharpened so the teaching lands without braking the round.

The teaching is **in the mechanic, not bolted on**: you cannot score without
inferring the rule, and every answer surfaces the rule by name plus a one-line
explanation. The v2 change preserves this — the rule + teach now ride a
non-blocking toast (brief on a correct lock, longer and fuller on a miss) so the
explanation reaches you *without* the v1 reveal card stopping the clock.

## Concepts, by family
| Family | Concept | Example | One-line teach |
|--------|---------|---------|----------------|
| Arithmetic | constant difference | 3, 6, 9, 12 → 15 | add the same number each step |
| Geometric | constant ratio | 2, 4, 8, 16 → 32 | multiply each step; it explodes fast |
| Fibonacci | recurrence | 1, 1, 2, 3, 5 → 8 | sum of the two before |
| Squares | n × n | 1, 4, 9, 16 → 25 | each term is a number times itself |
| Growing gap | second difference | 1, 2, 4, 7 → 11 | the gap grows by 1 (triangular) |
| Alternating | interleaved rules | +2, +5, +2 … | two rules take turns |
| Rotation | cyclic group on shapes | ↑ → ↓ ← | quarter-turn each step |
| Shape / Color cycle | periodicity | ●▲■●▲ | the pattern is the position |

## Skills exercised
- **Inductive reasoning** — infer a general rule from a few instances.
- **Arithmetic vs geometric discrimination** — the most common confusion; forced
  under time pressure.
- **Working memory** — hold 4–5 terms and project the next.
- **Error detection** — the "which one breaks the rule?" variant trains spotting
  a violation rather than producing a continuation (a harder, distinct skill).
- **Unaided recognition** — v2 hides the family chip at level 2+, so later in the
  run you must *name the family yourself*, raising the skill expression as you go.

## Why it accelerates learning
Difficulty ramps automatically with the clock: once the easy families are
fluent, subtler ones (Fibonacci, alternating, negative steps), longer sequences,
a shorter answer window, and the odd-one-out variant appear — keeping the player
in the productive-struggle zone. Because v2 removed the per-answer wall, the
player meets **many more** puzzles per round, so the recognition reps compound
faster within a single 50-second session.

## Curriculum tie-in
Maps to early-algebra and discrete-math standards on sequences, ratios, and
function rules — compressed into a reflex game met dozens of times per session.
